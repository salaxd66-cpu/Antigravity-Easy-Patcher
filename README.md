# Antigravity Easy Patcher

Графическая утилита для управления агентами Antigravity. В окне есть отдельные карточки для Antigravity IDE, CLI, расширения VS Code и Antigravity App.

## Использование

1. В Windows распакуйте архив целиком и запустите `Antigravity-Easy-Patcher.exe`. Для Ubuntu используйте запуск из исходников или соберите приложение по инструкции ниже.
2. Найдите нужную карточку. Кнопка **Файл…** позволяет указать агент вручную или вернуться к автопоиску.
3. Закройте выбранную программу, затем нажмите **Пропатчить** или **Восстановить**. Окно покажет точный путь перед записью.

Карточки с общим файлом `agy` отмечены в окне. Изменение такого файла действует на все программы, которые его используют. Две отдельные копии агента можно изменять независимо.

Утилита распознаёт проверенные сборки `agy` **1.5.5–1.5.7 для Windows x64** и **1.5.5, 1.5.7 для Linux x64** по контрольным суммам. Для более новых версий она ищет два уникальных фрагмента машинного кода в исполняемых секциях x64 и проверяет контрольную сумму результата перед записью. Так обнаружена локальная сборка **Windows 1.5.8**. Если структура агента изменится и сигнатуры не совпадут, утилита откажется менять файл. Совместимость будущих версий не гарантируется. Linux 1.5.7 проверен по официальной сборке и контрольным суммам; запуск на Ubuntu ещё не проверялся.

При применении правки утилита сверяет SHA-256 и сохраняет исходный файл рядом с агентом как `.agybak`. После обновления агента прежняя исходная копия сохраняется отдельно как `.agybak-<хеш>.old`, а новая становится `.agybak`. Это позволяет повторно применить патч без обновления самой утилиты, пока сигнатуры подходят. Восстановление требует исходной копии именно текущей сборки. Автоматического изменения файлов в фоне нет: после обновления агента снова нажмите **Пропатчить**.

В патче изменяется обработка `UNSUPPORTED_LOCATION` внутри проверки личного аккаунта. Агент выполняет обычный вход и загрузку моделей. Утилита работает с локальными файлами.

## Сборка

На целевой ОС установите Python 3.11–3.14 и запустите:

```sh
python -m pip install -r requirements-build.txt
python -m PyInstaller Antigravity-Easy-Patcher.spec
```

Для запуска из исходников выполните `python antigravity_easy_patcher.py`. В Ubuntu для сборки PyInstaller с системным Python могут понадобиться `python3-venv`, `libpython3.14` и `binutils`. Для запуска графического окна нужна обычная сессия рабочего стола.

В релиз прикрепляйте всю папку `dist/Antigravity-Easy-Patcher`, включая `_internal`. Исходники утилиты распространяются по GPL-3.0. Лицензии компонентов готовой сборки лежат в папке `licenses` рядом с приложением.
